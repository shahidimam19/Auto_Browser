Auto_Browser

High-performance browser built for real-time network traffic recording, automatic auth token extraction, anti-detect web browsing, and effortless task automation.

💬 WhatsApp Web 🔍 Google 🧪 HttpBin API 🐙 GitHub

⚡ What This Browser Does

🔴

1-Click Full Traffic Recording

Captures all HTTP/HTTPS network traffic, query parameters, headers, cookies, and complete response payloads directly via Chrome DevTools Protocol.

🔑

Automatic Auth Token Capture

Automatically intercepts Bearer tokens, API credentials, and session cookies across network requests and saves them directly to tokens.json & CSV.

📁

Organized Sessions & Tasks

Automatically groups browsing sessions into recordings/ with local timestamps. Save and transfer your best captures directly into permanent tasks/.

🛡️

Anti-Detect & Clean Identity

Runs with a clean, standard Google Chrome identity, stripping Electron automation signatures for full compatibility with WhatsApp Web and Google login.
